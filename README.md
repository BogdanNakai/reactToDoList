# 📝 Task Manager App

**Task Manager App** is a modern React web application designed for efficient personal and project task management. Built with user-specific accounts, it provides a personalized workspace featuring real-time editing, sorting, filtering, and session persistence.

---

## ✨ Key Features

### 🔐 Authentication & Personalization
* **User Accounts:** Secure authentication allowing users to log in to their private task workspaces.
* **Session Persistence:** Remembers authenticated users across page reloads and browser sessions.
* **Data Isolation:** Ensures each user accesses and manages only their personal task lists.

### 📋 Full Task Management (CRUD)
* **Create:** Quickly add new tasks with titles, descriptions, due dates, or priority levels.
* **Inline Editing:** Instantly rename or update task details without losing context or status.
* **Status Controls:** Easily toggle task states between *Active* and *Completed*.
* **Delete:** Remove individual tasks or clear completed items in bulk.

### 🧹 Organization, Sorting & Search
* **Flexible Sorting:** Order tasks dynamically by creation date, deadline, priority, or alphabetical title.
* **Filtering:** Filter tasks by category (*All*, *Active*, *Completed*).
* **Live Search:** Instant keyword search across task titles and descriptions.

### 💾 Data & State Management
* Continuous synchronization of user preferences, filtering state, and task updates.

---

## 🛠 Tech Stack

* **Frontend:** React (Hooks, State Management)
* **Routing:** React Router
* **Styling:** Tailwind CSS / Modern CSS
* **Data Storage:** REST API / `localStorage`
